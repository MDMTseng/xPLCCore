# Archived one-shot probes

Diagnostics that were useful for a single investigation and aren't part
of any regular workflow. Kept here rather than deleted in case the same
investigation needs to be repeated; not maintained -- treat as
read-only history.

If you find yourself wanting to import or call any of these from
something else, lift the relevant code into a proper named tool under
`codesys_scripts/` first, don't depend on `_archive/`.
