## 4. Gotchas learned the hard way

- After a **machine power cycle** the EasyCAT's USB-powered ESP32 needs a
  reset too (it and the LAN9252 stay powered, the LAN9252 loses the IRQ
  setup that only `EASYCAT.Init()` at boot writes), then a re-download to
  get the EasyCAT out of INIT. A PLC app stop/start alone does not need
  it: 2026-10-06 19:47 IDE download + start, ESP32 untouched, serial
  showed `"esc":"OP","sync":1`, interval 999-1001 us, `sync_irqs` equal to
  the PLC's EtherCAT cycles. Check it without resetting: open the ESP32's
  CP210x port (COM4 on the new PC) with `dtr = False; rts = False` set
  before `open()` and read the 100 ms JSON lines (`sync` 1 = SYNC0-driven).
  A default open toggles DTR/RTS, resets the ESP32 and breaks the bus.
- `GA_EV 8` (EV_RESET) from UnInited restarts a faulted bus without a
  download.
- The CODESYS daemon retires after 4 h; `deploy.py` restarts it before a
  deploy, not in the middle. After a daemon restart `plc_guard` may think
  the project differs: `rpc.py mark-synced --i-know` only if you KNOW the
  PLC runs this project.
- Harness: only one may run (it refuses a second bind); restarting it
  writes a new token that the tools read automatically.
- Sim: never HOME_GO (failed homing leaves the virtual axes in a pose where
  every G1 trips GroupErrorStop until a re-download); `GVL.SimNoFieldbus :=
  TRUE` after each download; re-run `sim_patch_trans.py` after each import.
- Git Bash has no node on PATH: the pre-push hook needs
  `export PATH="/c/Program Files/nodejs:$PATH"`.
- Not in the repo on purpose: test data under `codesys_scripts/jobs/`
  (sweeps, soak logs, `drive_params_backup.json` = the drives' original
  parameters before the sweeps; copy it over by hand if you need it).
