# ASDA-B3-E CSP 目標位置取錯週期：簡短摘要

**現象：** ASDA-B3-E（韌體 B3-E-Ver22106）在 CSP + DC SYNC0（1 ms）下，
每隔 2.4–3.6 秒出現一陣數 ms 到數十 ms 的突波。突波中驅動器取用了錯誤
週期的目標位置（0x607A）：
- 內插斜率跳成 2–3 倍；
- 命令位置在 1/8 ms 內跳動最多約 200 PUU。

delta 手臂因此有輕微撞擊和振動。

**最小重現：** 不經過運動函式庫，由 PLC 直接寫 controlword 和每 1 ms
精確 +145 PUU 的等速斜坡。從驅動器回讀的 0x6062：
- 有 3–6 % 的週期取到晚一格的目標，少數取到早一格的目標；
- 速度減半，發生率不變；
- ASDA-Soft 示波器同時看到週期性突波（2.37 → 2.58 → 3.5 秒循環）。

**已排除：**
- 主站軌跡、frame 內容、掉包；
- 線路末端的 SYNC0 時序（ESP32 + LAN9252 量測，0 異常）；
- 速度、週期時間（1 / 2 ms）、P3.009.Z、USB 監控；
- 驅動器 0x1C32 同步計數器一直為 0。

**新發現（10-01 下午）：**
- 相同韌體的 EAxis1、EAxis2 幾乎在同一時刻出錯（13 次中 13 次在 500 ms
  內）。
- 更新韌體後的 EAxis0 在不同時刻出錯，但週期相同。
- 換成出廠參數，結果也一樣。

推測：主站 frame 相對 SYNC0 有緩慢的週期性時序漂移，而各韌體取資料的
時間點不同。

**請台達回覆：**
1. 是否為已知問題？是否有修正韌體？
2. RxPDO 鎖存時間點，以及內部時脈如何鎖定 SYNC0（是否有週期性修正）。
3. 建議的設定（P3.009、SYNC0 偏移、SYNC1 等）。
4. 是否有每週期的同步狀態可讀。
5. 新韌體在 RxPDO / SYNC0 處理上的改變，以及要求的 frame 到達時間窗。
